# Trilha | Mentoria de carreira

Aplicação web em Flask que usa qualidades, desafios, habilidades e interesses para sugerir áreas profissionais e oferecer links de busca por vagas.

## Executar localmente

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Acesse http://127.0.0.1:5000. As recomendações são geradas localmente por regras simples; a busca por vagas abre resultados do Google Jobs em outra aba.
